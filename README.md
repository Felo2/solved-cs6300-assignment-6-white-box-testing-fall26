<p class="MsoNormal" style="text-indent: -18.05pt; mso-list: l3 level2 lfo7; margin: 0cm .15pt .25pt 58.55pt;"><!-- [if !supportLists]--><span style="mso-list: Ignore;">c.<span style="font: 7.0pt 'Times New Roman';">&nbsp;&nbsp;&nbsp; </span></span><!--[endif]--><b style="mso-bidi-font-weight: normal;"><span style="color: red;">throw new ArithmeticException.</span></b> The code should <b style="mso-bidi-font-weight: normal;">naturally fail due to an arithmetic operation</b> that results in a divide-by-zero exception.

<p class="MsoNormal" style="text-indent: -18.05pt; mso-list: l3 level2 lfo7; margin: 0cm .15pt .25pt 58.55pt;"><!-- [if !supportLists]--><span style="mso-list: Ignore;">d.<span style="font: 7.0pt 'Times New Roman';">&nbsp;&nbsp; </span></span><!--[endif]--><b style="mso-bidi-font-weight: normal;"><span style="color: red;">Loops</span></b>.<span style="mso-spacerun: yes;">&nbsp; </span>(while, for, do, etc.)

<p class="MsoNormal" style="text-indent: -18.05pt; mso-list: l3 level2 lfo7; margin: 0cm .15pt .25pt 58.55pt;"><!-- [if !supportLists]--><span style="mso-list: Ignore;">e.<span style="font: 7.0pt 'Times New Roman';">&nbsp;&nbsp; </span></span><!--[endif]--><b style="mso-bidi-font-weight: normal;"><span style="color: red;">Method calls</span></b>.<span style="mso-spacerun: yes;">&nbsp; </span>Your method should be self-contained and not call any other methods (including itself).

<p class="MsoNormal" style="text-indent: -18.05pt; mso-list: l3 level2 lfo7; margin: 0cm .15pt 0cm 58.55pt;"><!-- [if !supportLists]--><span style="mso-list: Ignore;">f.<span style="font: 7.0pt 'Times New Roman';">&nbsp;&nbsp;&nbsp; </span></span><!--[endif]--><b style="mso-bidi-font-weight: normal;"><span style="color: red;">Conditional (trinary) operators</span></b>.<span style="mso-spacerun: yes;">&nbsp; </span>(No use of the “&lt;condition&gt; ? &lt;case if true&gt; : &lt;case if false&gt;” construct.)
